# 大饼

## 插件大饼：

- 完善圆桌会议（辅助头脑风暴、角色扮演）
- 机器人控制插件：接入实体机器人，控制实体机器人
- 小说创作插件：接入我的另一个项目AutoWriter，自动创作小说
